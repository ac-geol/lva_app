SPARSEDENSE
What is in the export, and what to trust

Angles

Dip
0–90°, measured down from horizontal.
DipAzimuth
0–360°, the true down-dip direction measured clockwise from north. Leapfrog's convention, verified.
Pitch
0–180°, the rake of the long axis within the plane, measured from the strike direction. Not yet verified against Leapfrog — see below.

Everything else

Planarity
0–1. How clearly a single plane is defined at that point. Low values are weakly constrained.
Linearity
0–1. Whether there is a real long axis in the plane. Pitch is only written where this is above 0.05.
LocalN, LocalHoles
How many neighbouring samples, and how many separate holes, the estimate was built from.
VsReferenceDeg
Degrees between this orientation and what the drill pattern alone would report. Travels with the file so a decision made from it can be audited later.
Estimator
Which method produced the row.

Before you code grades from this

Dip and dip azimuth are settled. Pitch is provisional: the direction it is measured in has not been confirmed against a Leapfrog round trip, and a reversed pitch gives an ellipsoid that is correctly oriented as a plane but whose long axis points the wrong way inside it. Run scripts/make_convention_check.py and follow docs/LEAPFROG_CHECK.md once, then this note can go.

Orientations within one search radius of the edge of your exported volume lean toward that cut face, because the neighbours beyond it are not in the file. Trim the rim, or export a wider margin next time.
